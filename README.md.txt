# Forward Fitness Club Website

## Project Overview

Forward Fitness Club is a multi-page website developed as part of my web development coursework. The website represents a fictional fitness center and provides information about fitness services, group classes, nutrition, and membership inquiries.

## Pages

- **Home:** Introduction to Forward Fitness Club.
- **About:** Information about the fitness center and its services.
- **Classes:** Group fitness classes and schedules.
- **Nutrition:** Nutrition information and recommendations.
- **Contact:** Contact information and membership inquiry form.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Skills Demonstrated

- Front-end web development
- Website structure and organization
- CSS styling and layout
- JavaScript functionality
- HTML forms and tables
- Multimedia integration
- Website navigation

## Project Purpose

This project demonstrates my foundational front-end development skills and ability to build and organize a multi-page website. It is included in my technical portfolio to showcase practical experience with web development.
